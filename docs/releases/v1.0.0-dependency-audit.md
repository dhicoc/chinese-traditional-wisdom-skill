# v1.0.0 依赖与供应链审计

> 审计日期：2026-08-21

## Node / pnpm

- 使用 npm 官方 audit endpoint（本机默认华为镜像不支持 audit POST）。
- 初次发现：`postcss → nanoid 3.3.17` 命中 GHSA-2v37-7h3g-55p8（high）。
- 修复：在 `apps/visual/pnpm-workspace.yaml` 固定 override `nanoid: 3.3.18`，刷新 lockfile。
- 最终：`pnpm audit --prod --audit-level high --registry=https://registry.npmjs.org` 返回 **No known vulnerabilities found**。
- `esbuild@0.28.2` 是唯一允许执行安装脚本的依赖，记录于 `onlyBuiltDependencies`。

## Python 离线 oracle

- 全局 Python 环境存在与本项目无关的包冲突，因此不作为发布证据。
- 在全新 Python 3.13 venv 中安装 `requirements.txt`，`pip check` 通过，lunar-python / iztro-py / requests 导入与合成 smoke 通过。
- 原 `ichingshifa==0.1.0` 已从索引消失；当前 3.1.9 的 `sxtwl` 在部分平台没有 wheel，可能要求 C++ Build Tools。因此迁移到 `requirements-optional-liuyao.txt`，不阻塞默认完整安装，也不影响 TypeScript 权威六爻工具。
- `scripts/ziwei_calc.py` 已适配 `iztro-py 0.5.0` API。
