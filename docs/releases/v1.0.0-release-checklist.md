# v1.0.0 发布与回滚清单

## 发布策略

- 类型：首个稳定正式版本；无流量切换和服务端迁移。
- Tag：`v1.0.0`，annotated tag。
- GitHub Release：正式版，不标记 prerelease。
- 资产：Skill 源码归档、Dashboard 静态构建归档、SHA-256 校验清单。

## 发布门禁

- 工作树干净且 `main == origin/main`；
- `pnpm eval:skill` 19/19；
- 本地第 9 节完整质量门；
- 四浏览器 E2E 全绿；
- `pnpm audit --prod` 与 `pip check`；
- 全新目录冻结安装、CLI 与 Dashboard 冷启动；
- Release 资产 SHA-256 与下载后校验一致。

## 回滚

- 代码回滚点：`9538c67`（发布文档前、功能已全量验证）。
- 删除错误 Release 不删除本地数据；本项目无远端用户状态。
- 若只撤回文档/资产，保留 tag 前先核对 tag commit；不要移动已公开 tag，改发补丁版本。

## Canary

发布后执行：

1. 从 tag 新克隆；
2. 冻结安装；
3. `engine:list`、`engine:plan`、`engine:compare-rules`；
4. `pnpm eval:skill`；
5. Dashboard preview + Chromium/WebKit smoke；
6. 校验 GitHub Release 资产和 SHA256SUMS。
