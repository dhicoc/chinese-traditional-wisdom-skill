# Chinese Traditional Wisdom Skill v1.0.0

这是首个稳定正式版本，提供本地优先、可复核的中国传统文化 Agent Skill 与 Dashboard。

## 亮点

- **32 个本地工具**：八字、紫微、六爻、梅花、奇门、六壬、太乙、皇极、星宿、黄历、风水、姓名、解梦、体质及联合分析。
- **完整 Agent 闭环**：发现、描述、输入校验、计算、claims 核验、类型化呈现、结果包。
- **24 个 Dashboard 工作区**：桌面与移动端四浏览器覆盖。
- **知识产品化**：41 项知识 Manifest、30 部古籍全文、95 个稳定章节、全文检索与深链接。
- **规则透明**：时辰不确定性分析和 6 类规则/流派差异比较，不裁定唯一正确流派。
- **隐私优先**：无账户、无远端计算；历史默认不保存，结果包不含原始输入。
- **质量门**：800 项单测、19 项 Skill eval、456 项四浏览器 E2E。

## 安装

要求：

- Node.js `24.12.x`
- pnpm `10.26.1`
- Python + pip（仅安装离线 oracle；不是用户计算来源）

Windows：

```powershell
scripts\setup.bat
```

Linux/macOS：

```bash
bash scripts/setup.sh
```

Dashboard：

```bash
pnpm dev
```

Agent CLI：

```bash
pnpm engine:list
pnpm engine:describe bazi_calculate
pnpm engine:plan --query "想看今年事业"
pnpm engine bazi_calculate src/__fixtures__/local-tools/bazi_calculate.success.json
```

## 从预发布代码升级

本版本是首个正式 tag。若从早期 main 分支升级，请注意：

1. 八字 CLI 必须提供 `timeBasis`；民用时间需 `civilFallbackConfirmed: true`。
2. 真太阳时必须提供完整 `trueSolarResolution`，不能只传校正后的时刻。
3. 日期敏感工具必须显式传入年份、月份或完整日期。
4. 本地历史不再自动写入；需要在保存预览中主动确认。
5. 结果包不可 replay，不包含原始输入。

详细工具输入见 `tool-index.md`，规则变化见 `docs/RULE-CHANGELOG.md`。

## 兼容性

- 32 个工具名称保持稳定。
- 原有 `pnpm engine <tool> <input.json>` 入口保留。
- Dashboard 继续直接调用浏览器安全纯引擎，不经过 CLI Runner。
- 旧 history schema v0/v1/v2 可读取并重新脱敏。

## 已知限制

- 真太阳时的地点、历史时区和夏令时证据必须由外部可靠来源核验，本项目不联网补造。
- Python 结果不能作为 Agent 对话中的权威计算结果。
- 遗留 `ichingshifa` 六爻 oracle 为可选安装；在缺少 `sxtwl` wheel 的平台可能需要 C++ Build Tools，不影响默认完整安装或 TypeScript 六爻工具。
- 传统解释、建议、应期和现实效果不属于 claims 校验范围。
- P0-03、P1-02、P3-04 按产品决定不实施。

## 回滚

发布只包含本地代码和静态资产，没有数据库迁移或远端状态。需要回滚时：

```bash
git switch --detach 9538c67
pnpm --dir apps/visual install --frozen-lockfile
pnpm typecheck
```

恢复到 v1.0.0：

```bash
git switch --detach v1.0.0
```
